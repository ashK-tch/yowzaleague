# Theme song

Put one audio file in this folder and the site's jukebox plays it instead of the
built-in theme song.

- Formats: `.mp3` (best), `.m4a`, `.aac`, `.ogg` or `.wav`.
- Keep it under about 10 MB so it starts quickly on phones. GitHub's upload limit is 25 MB.
- The file name becomes the title that scrolls across the jukebox, so name it the way
  you want it shown (`Yowza Anthem.mp3` shows as YOWZA ANTHEM).
- Only one file is used. If there are several, the first one alphabetically plays.
- The file is published on the public site, so use a track you have the rights to.

## How to add or change it on GitHub

1. Open this `music` folder on github.com.
2. Click **Add file > Upload files**, drag in your audio file, and click **Commit changes**.
3. To swap songs later, delete the old file here (open it, then the trash icon), and upload the new one.

The site rebuilds itself about a minute after each change. Visitors hear the song after
they click **Enter with music** on the welcome dialog, or press Play in the jukebox.

To go back to the built-in theme song, delete the audio file and leave this README.
